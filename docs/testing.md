# Порівняння у KLANext

Файли `*.uk.ansi.txt` — JSON для імпорту на [klanext.keyboard-design.com](https://klanext.keyboard-design.com/). ЙЦУКЕН для контрольного порівняння збережено [окремо](../layouts/reference/ytsuken/ytsuken.uk.ansi.txt).

## Як порівняти

1. Завантаж TXT потрібних розкладок і ЙЦУКЕН. На сторінці файла GitHub користуйся завантаженням сирого файла, а не збереженням HTML-сторінки.
2. Імпортуй файли через функцію імпорту розкладки в KLANext.
3. Візьми той самий текст для всіх учасників: [test.text.txt](../data/test.text.txt), [test.text.modern.txt](../data/test.text.modern.txt) або власний.
4. Перевір тип клавіатури, призначення пальців і руку для пробілу. Для окремого порівняння LT/RT зміни лише палець пробілу в аналізаторі й збережи обидва результати.
5. Запиши назву тексту, параметри й результат разом. Бали з різних текстів або налаштувань не утворюють спільного рейтингу.

У файлах ergoLAY1g0–1g4 та ergoLAY1a3–1a7 пробіл призначено лівому великому пальцю. У ergoLAY1a0–1a2 і контрольній ЙЦУКЕН — правому. Для ранніх розкладок призначення наведено в [каталозі](versions.md).

Файли аналізатора задають один пробіл, а всі три надані KLC — лігатуру з двох пробілів на звичайному Space. У виправленому автором імпорті 1g4 шари `%` і `₴` вже збігаються з KLC; старе прев’ю ще не оновлено. Тому оцінка імпорту не описує всі особливості відповідного Windows-проєкту. [Точні відмінності](audit.md).

## Пробіл і AltGr

За спостереженнями автора, у звичній ЙЦУКЕН пробіл правою рукою дає кращий результат, а в ergoLAY із багатьма символами на правому AltGr вигідніше натискати пробіл лівою. Наданий скриншот показує цей напрямок для відповідних пар. Це висновок для цих тестів і пальцювання; зручність у щоденному друці варто оцінювати окремо.

## Тексти й таблиці n-грам

Два TXT збережено в оригінальному UTF-8. Таблиці `test.text.2grams.short.csv` і `test.text.3grams.short.csv` читаються як Windows-1251, роздільник — крапка з комою. Вони містять номер, n-граму, кількість входжень та відносну частоту. Відкривай їх через імпорт CSV із відповідним кодуванням.

Походження CSV, початковий корпус, програма експорту та їх використання під час розробки не встановлені. Наявні дані не дають підстав приписувати їх Gephi. Так само не встановлено джерела й умови поширення двох тестових текстів.
