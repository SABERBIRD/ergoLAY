# Встановлення у Windows

У наданому архіві є три зібрані пакети:

| Версія | Завантаження | Імена всередині пакета |
| --- | --- | --- |
| ergoLAY1g0 | [ZIP](../installers/ergoLAY1g0-windows.zip) | `setup leus1g`, `LEUS1G` |
| ergoLAY1g1 | [ZIP](../installers/ergoLAY1g1-windows.zip) | `setup leus1g1`, `LEUS1G1` |
| ergoLAY1g4 | [ZIP](../installers/ergoLAY1g4-windows.zip) | `ergolay`, `ergoLAY` |

1. Відкрий посилання на ZIP і завантаж файл через кнопку завантаження GitHub. Якщо завантажуєш увесь репозиторій, використай **Code → Download ZIP**.
2. Повністю розпакуй архів потрібного інсталятора в окрему папку.
3. Запусти `setup.exe` всередині розпакованої папки та виконай кроки майстра. Залиш MSI й папки з DLL поруч із ним.
4. Відкрий налаштування мови Windows → українська мова → параметри клавіатур і за потреби додай встановлену розкладку. Точні назви пунктів залежать від версії Windows.
5. Перемикай розкладки через `Win + Space`. Якщо нова розкладка ще не з’явилася, вийди з облікового запису й увійди знову.
6. Перевір основні літери, Shift, AltGr, Shift+AltGr і потрібні тобі клавіатурні скорочення в текстовому редакторі.

Пакети містять `setup.exe`, MSI та DLL для архітектур, зазначених у папках `i386`, `amd64`, `ia64`, `wow64`. Наявність цих файлів не підтверджує сумісність із конкретною сучасною Windows; ARM64-пакета в архівах немає. Під час упорядкування перевірено читабельність ZIP та склад пакетів, але встановлення на Windows не запускалося.

У всіх трьох KLC звичайний Space описано як лігатуру з двох пробілів; Shift+Space задає один пробіл. Для 1g4 KLC має `%` на основному шарі та `₴` на Shift фізичної клавіші апострофа QWERTY, виправлений імпорт KLANext має той самий порядок. Старий PNG ще показує зворотний порядок. Перевір цю поведінку після встановлення: зібрані DLL окремо не аналізувалися. [Подробиці перевірки](audit.md).

## Редагування й збірка

Проєкти Microsoft Keyboard Layout Creator (MSKLC) є для [ergoLAY1g0](../layouts/gephi/ergoLAY1g0/ergoLAY1g0.klc), [ergoLAY1g1](../layouts/gephi/ergoLAY1g1/ergoLAY1g1.klc) і [ergoLAY1g4](../layouts/gephi/ergoLAY1g4/ergoLAY1g4.klc). Відкрий `.klc` у MSKLC, перевір розкладку і скористайся **Project → Build DLL and Setup Package**, якщо потрібна власна збірка. Умови роботи MSKLC на твоїй системі слід перевірити окремо.

Для решти версій є матеріали для аналізу; імпортний `.txt` KLANext не є Windows-інсталятором чи проєктом MSKLC. Назви в KLC та зібраних пакетах можуть відрізнятися від назв папок у репозиторії. Пакети збережено без перезбирання, і відповідність їх поведінки поточним KLC не перевірялася.
