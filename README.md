# ergoLAY — ергономічна українська розкладка

Власна українська розкладка, що розвивається через практику друку, аналіз текстових корпусів і експерименти з AI. Частина літер та додаткових символів доступна через **AltGr**. У корпусній гілці й новіших AI-прототипах пробіл призначено лівому великому пальцю, а AltGr — правій руці.

**Проєкт у розробці.** Тут зібрані робочі матеріали різних етапів: для частини версій є Windows-інсталятори, для інших — файли аналізу й прев’ю. Більший номер означає наступний варіант, а не гарантовано кращу розкладку.

[Усі версії та прев’ю](docs/versions.md) · [Встановлення у Windows](docs/install.md) · [Порівняння в KLANext](docs/testing.md) · [Історія та назви](docs/history.md)

## Основна версія: ergoLAY1g4

Остання надана версія гілки, розробленої з використанням корпусів, біграм, триграм і Gephi 0.10.1. Є проєкт MSKLC та готовий архів інсталятора. Автор використовує **ergoLAY1g4 щодня**.

![ergoLAY1g4 — основний шар і додаткові символи](layouts/gephi/ergoLAY1g4/ergoLAY1g4.png)

[Інсталятор Windows](installers/ergoLAY1g4-windows.zip) · [Проєкт MSKLC](layouts/gephi/ergoLAY1g4/ergoLAY1g4.klc) · [Імпорт у KLANext](layouts/gephi/ergoLAY1g4/ergoLAY1g4.uk.ansi.txt)

У наданих KLC звичайний Space задає **два пробіли**, Shift+Space — один. Виправлений автором імпорт 1g4 узгоджено з KLC: `%` на основному шарі, `₴` на Shift. На старому прев’ю ці два символи ще показані навпаки. Ці особливості збережено; деталі — у [перевірці файлів](docs/audit.md).

## AI-експеримент: ergoLAY1a6

Раніше — `LTprototype-0.3-altgr`. Цей варіант отримав найменший Overall Score на наданому автором скриншоті KLANext: **111.00**. Це результат конкретного порівняння; текст і повні параметри того запуску не зафіксовано. Windows-інсталятора для цього варіанта в наданих файлах немає.

![ergoLAY1a6 — раніше LTprototype-0.3-altgr](layouts/ai/ergoLAY1a6/ergoLAY1a6.png)

## Як розвивався проєкт

`ergoLAY0–ergoLAY8` — ранні спроби знайти зручне розміщення простим ручним перетягуванням клавіш навмання.

`ergoLAY1g0–ergoLAY1g4` — перехід до корпусів, Gephi 0.10.1, біграм і триграм; за оцінкою автора, саме тут відбувся основний ривок у якості розкладки.

`ergoLAY1a0–ergoLAY1a7` — упорядковані матеріали AI-гілки на основі ergoLAY1g4: контрольна реконструкція, кандидати оптимізації та проміжна схема для подальших розрахунків. [Таблиця старих і нових назв](docs/history.md) пояснює походження кожного файла.

## Що завантажувати

| Мета | Файли |
| --- | --- |
| Встановити на Windows | ZIP у [installers](installers), далі [інструкція](docs/install.md) |
| Редагувати у Microsoft Keyboard Layout Creator | `.klc` у папці відповідної версії |
| Порівняти розкладки | `.uk.ansi.txt` для [KLANext](https://klanext.keyboard-design.com/) і тексти з [data](data) |
| Подивитися розташування клавіш | Два основні прев’ю тут і [повна галерея](docs/versions.md) |

Файли `.uk.ansi.txt` містять JSON у форматі імпорту KLANext. `uk` — код української мови; у назвах файлів ним замінено `ua` та виправлено скорочення `ans` на `ansi`. Ці зміни стосуються лише зовнішніх назв.

## Робочі назви всередині файлів

Розробка тривала кілька місяців із перервами; назва **ergoLAY** з’явилася пізніше, а згодом до роботи долучився AI. Тому всередині файлів, інсталяторів і старих нотаток трапляються `leus`, `LEUS1G`, `LTprototype`, старі номери, чернеткові описи та інші неточності.

**Вміст усіх перенесених файлів збережено байт у байт.** Змінено лише їх розташування та зовнішні назви; додано документацію. Внутрішні назви інсталяторів і KLC не виправлялися. Відповідність оригіналам і SHA-256 наведені в [маніфесті](docs/source-manifest.csv).
